# Đăng nhập OAuth2

## Ví dụ với GitHub

1. Truy cập https://github.com/settings/applications/new để tạo OAuth App mới.

2. Cài đặt địa chỉ callback (Authorization callback URL): `https://<ten-mien-tuy-chinh-worker-cua-ban>/login`

<img src="../public/images/oauth2/github-oauth1.png" class="article-img" />

3. Sau khi tạo Client Secret, vào Cài đặt hệ thống trong Cloud Mail để cấu hình Client ID và Client Secret.
<img src="../public/images/oauth2/github-oauth.png" class="article-img" />
